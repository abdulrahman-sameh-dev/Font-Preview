# Eaalim Font

Arabic font package for web projects.

## Installation

```bash
npm install eaalim-font
# or
yarn add eaalim-font
```

## Usage

1. Import the font in your CSS/SCSS:
```css
@import 'eaalim-font';
```

Or in your JavaScript/TypeScript:
```javascript
import 'eaalim-font';
```

2. Use the font in your CSS:
```css
.your-element {
  font-family: 'eaalim-font', sans-serif;
}
```
